# Task Phase1-04: 列表 UI 与交互

> 依赖: 02/03 | 被依赖: 05
> 对应 README: 模块 1 全部、模块 3 要求 7

## 目标
实现主列表视图:分组折叠、拖拽排序、搜索、批量操作、删除确认、空状态与响应式适配。

## 具体工作
1. 主列表视图:
   - "未分组"条目置顶 (虚拟分组,无折叠头)
   - 分组可折叠;空分组点击展开无反应 (不渲染占位容器)
   - 条目行: 左侧首字母占位符 (issuer 哈希配色) | 中部 issuer + label | 右侧大字号验证码 (3+3 / 4+4 分组) | 更多菜单
   - 点击验证码纯数字复制,toast 提示,不自动清除剪贴板
   - 底部倒计时进度条,≤5s 变红
2. vuedraggable:
   - 组内条目排序
   - 分组本身排序
   - 不实现跨组拖拽;拖拽结束持久化顺序
3. 全局搜索 (顶栏常驻):
   - issuer / label / 分组名,大小写不敏感子串
   - 命中分组临时展开,清空恢复原展开状态
   - 无结果空态文案 (中英文)
4. 批量模式: 长按条目进入多选,顶部"已选 N 项"+ 操作栏 (移动到分组 / 删除 / 取消)
5. 删除确认交互:
   - 单删: 弹窗显示 issuer + label
   - 分组删: 弹窗勾选框"同时删除分组内条目",默认未勾选
6. 空状态引导: 无数据时三按钮 (扫码添加 / 手动添加 / 从文件导入) + 简介文案
7. 响应式: `el-dialog` → 移动端 `el-drawer(direction="btt")`,Flexbox 布局,`useBreakpoints`
8. 设置页入口: 顶栏,仅语言切换 (中英文 + 跟随系统)

## 验收标准
- [ ] 桌面/移动断点下布局正常,抽屉与弹窗各端表现正确
- [ ] 拖拽排序持久化,刷新后顺序保留
- [ ] 搜索过滤与临时展开/恢复行为正确
- [ ] 批量移动到分组、批量删除符合规则
- [ ] 删除分组默认保留条目进"未分组",勾选后连同删除
- [ ] 空状态三按钮路由到对应入口
- [ ] 所有文案走 i18n,中英文均完整无 hardcode
