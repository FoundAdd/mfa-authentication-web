# Task Phase2-10: 同步设置、设备 UI 与导入导出整合

> 依赖: 09 | 被依赖: 12
> 对应 docs/Phase2.md: §9、§10、§11

## 目标

把云同步能力接入现有 `SettingsDialog.vue`、导入导出流程和备份提醒,提供最小但完整的用户操作闭环和 12 语言文案。

## 具体工作

1. `SettingsDialog.vue` 新增“云同步”区块:
   - 默认关闭;开启前展示服务端可解密的数据边界。
   - 状态: 已同步、同步中、离线、需要登录、失败、云端已删除。
   - 展示上次成功同步时间和“立即同步”按钮。
2. 首次绑定向导:
   - 本地/云端数量摘要。
   - 分支: 合并(默认)、云端覆盖本地、本地覆盖云端。
   - 覆盖分支要求先导出备份并二次确认。
3. 设备管理:
   - 展示设备名称、平台、最后同步时间和状态。
   - 支持重命名、撤销;不提供远程擦除。
   - 明确说明强撤销依赖 Access 会话撤销。
4. 生命周期操作:
   - 关闭同步: 保留本地和云端。
   - 解除账号绑定: 保留本地,云端可选保留。
   - 删除云端数据: 重新认证 + 二次确认,保留本地。
   - 删除本机数据: 沿用现有数据损坏/重置语义,单独确认。
5. 导入导出:
   - 同步开启时覆盖导入转换为云端覆盖语义并提示影响所有设备。
   - `.totp` 导出不包含 SyncMeta、revision、device 或 tombstone。
   - 云同步健康时抑制重复本地备份提示;关闭或连续失败时恢复提醒。
6. i18n:
   - 补齐 `sync.*`、`device.*` 和错误文案。
   - `en`/`zh-CN` 完整,其余语言允许回退英文;更新 locales 一致性测试。

## 验收标准

- [ ] 同步默认关闭,启用前用户必须明确确认数据边界
- [ ] 首次绑定三种分支均有可理解文案和正确结果,覆盖不会静默执行
- [ ] 设置页能展示状态、上次同步时间、设备列表和手动重试
- [ ] 关闭同步、解除绑定、删除云端、删除本机四类操作语义不混淆
- [ ] 同步开启时覆盖导入确实同步 tombstone,导出仍保持 `.totp` v1 格式
- [ ] 12 个语言包键结构测试通过;移动端布局无横向溢出
- [ ] 组件测试覆盖状态、确认流程、设备操作和备份提示;lint/typecheck/test/build 通过
